# P_5.4：推拉与收纳实现摘要

2026-10-07 · **操作闭环与交互补齐已完成并提交，人工测试整体可用。** 本文保留结果、阅读入口和遗留边界；旧步骤及估算已收起，细节可查 Git 历史。规则见[玩法大纲第 2、3 组](../玩法大纲.md)，后续见[待办安排](../待办安排.md)。

## 已完成的操作

| 操作 | 当前行为 |
|---|---|
| 点按 | 地面选中普通箱／解除选中；收纳箱点按尝试原位取出 |
| 隔距选中 | 自动走近至贴合，再进入推拉；方向输入由走近行为接管，点按／跳跃可退出 |
| 推拉 | 贴合后共同水平运动，双方水平阻挡均有效，各自保留竖直运动；未选中普通箱可接触推动 |
| 退出 | 跳跃、撤销许可、走远、失去支撑或对象停用解除选中；落边后箱子独立下落 |
| 长按收纳 | 箱子保存当前世界矩形、关闭碰撞与运动、显示变暗；与其它收纳矩形重合时拒绝 |
| 取出 | 检查原位实心占用；成功先启用 Collider 再恢复运动参与，失败给出原因；收纳期间可穿过 |
| 提示与表现 | 预览和点按共用目标规则；单目标轮廓与文字提示，推拉面向箱子并复用移动动画 |
| 带电箱 | 不可选中；触碰任意面请求电击死亡，同一死亡周期去重 |

默认范围：外部交互 0.5、收纳箱取出 0.6、解除 0.8、贴合 0.05；取出占用矩形每边内缩 0.02。参数可调，尚未最终定标。

点按／长按调试打印已删除；收纳／取出拒绝按本次操作打印一次，预览不刷日志。自动走近遇阻不绕行；取出不自动换位置或挤开玩家。目标发现尚无隔墙遮挡核对，若关卡需要，须补局部检查。

## 框架边界与后续收束

**P5.4 完成不冻结底层算法。K11 已实现并通过自动回归，人工手感待核。** 原自研共同请求、AABB 纠偏／环境回算与组外 T+1 接触力退出；角色和箱子在相位 4 统一原生模拟，实际刚体速度成为跨帧基准。

保留六相位与规则时序，相位 1 主动读取上一步原生接触，相位 3 合成并写本步刚体速度，相位 5 回读实际运动。跳跃、墙滑／墙跳仍归行为与执行规则；操作关系和收纳事务保留。拉动采用竖直自由、水平贴合的原生滑动关节，锚点依据双方刚体实际位置差，跳跃或落边解除；普通接触推动不建立选中关系。

冰面、推拉手感仍是可调结构，尚未作为最终成品定标；替换算法可以重调，不要求复刻当前每个速度公式。具体范围见[K11](../历史回顾.md#k_11框架复杂度降低)。

前置整理已经落地：

- IsMotionReady 表示组装就绪，IsMotionPermitted 表示规则许可，IsMotionParticipating 表示实际参与；IsSupported 沿用配置探针表达箱底几何支撑，不代表精确原生承重接触。
- 暂停停止参与模拟并保留实际运动状态，操作退出解除水平约束；显式恢复才清理运动并重采样。
- 恢复顺序为 Collider → 参与同步 → 采样；simulated 仅在状态变化时写入，避免加载初期插值位置回写刚体。
- 旧壳和闲置成员已清理；K11 同步删除无用途求解接口与镜像算法检查，编辑器观测不参与决策。
