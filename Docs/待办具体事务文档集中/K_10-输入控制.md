# K_10：输入控制实现摘要

K10.1–K10.4 已完成（2026-10-04）；本文为当前实现，旧开工前问题与步骤已收起。玩法消费见[P5](P_5-玩家逻辑行为扩展.md)、[P5.4](P_5.4-执行编排.md)。

## 当前边界

| 内容 | 当前实现 |
|---|---|
| 动作来源 | 运行时只加载 Resources/player.json，基础 InputActionAsset 加载一次；不再替换 JSON 占位符，不维护第二份运行时动作来源 |
| 改键持久化 | InputBindingOverrides.json 只保存绑定覆盖；加载／保存由 DataAndInitMgr 负责 |
| 订阅与开关 | 重绑先卸旧订阅；改键完成恢复原输入开关与持续按住状态，不制造假边沿 |
| 控制目标 | BindPlayer 先解除旧玩家，再绑定新玩家；状态使用当前输入，只有控制目标消费跳跃／交互一次性边沿 |
| 点按／长按 | 默认 E，长按阈值 0.4 秒，互斥且各只产生一次；玩法由 Player 消费，P5.4 已删除测试打印 |
| 冲突处理 | 只接受键盘，返回时扫描有效绑定；冲突留在面板并显示 conflictT，不另维护一份按键名单 |

新增动作继续扩同一资产；游泳复用已有双轴输入。输入只发布事实，不拥有推拉、体力、游泳或阶段规则。
