# P27.3 第二页白字柔光样板

2026-10-19，P27.2获确认后实施。第二页9处文字改用原FZYTK字体生成的局部SDF字库：标题、说明、无效果提示、正负结果的标题与数值、最终体能和开始按钮。字面为白色，字外叠加克制的蓝白柔光，沿原迷雾扩散／显字／淡出时序显示。第一页继续原字体和少花纹纸样。

采用一份共享材质和一张2048×2048 Alpha8图集，图集本体约4 MiB；当前菜单中文、数字和符号提前装入，随资源包保存，保留动态补字能力。没有新增运行时相机、离屏模糊、独立文字叠层或逐标签材质实例。原有全局SDF字库和其它页面字体未改。

人工已将迷雾扩散调成1秒，本轮保留该值；显字0.3秒、退出0.16秒。已有8处文字矩形及第一页／认知条／背包等其它预设记录均保持，只新增独立的结果标题供第二页使用，避免改动第一页余额字样。
