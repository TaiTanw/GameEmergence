# F_6：二维运动建模实现摘要

F_6.1 与 F_6.2_1–7 的历史结果已随[K11](../历史回顾.md#k_11框架复杂度降低)收束为原生运动；K11 自动回归通过，人工手感待核。完整二维模型、旋转几何与多箱上坡未完成。现编号为 K6，文件名保留，不继续按旧步骤扩充自研求解。

## 已落地结果

| 范围 | 历史结果与 K11 去向 |
|---|---|
| F6.1 效果状态 | 曾统一持有环境速度、动态力累计与尾效；K11 只保留环境／限时命令参数，真实动量归刚体，来源关系仍归 EntityEnvironmentContext |
| 施力参数 | DynamicForceParameters 与 ForceData 保存当前参数、类型；旧累计状态与尾效已退出 |
| F6.2 运动快照 | 曾保存自由速度、自身运动、平台携带和基础位移；K11 改从刚体实际速度生成本步命令 |
| 候选环境 | 旧候选位置与请求裁剪随 K11 删除；探针和区域查询保留事实采样 |
| 请求／提交 | 旧有限回算与位移提交退出；K11 相位 4 统一模拟，相位 5 回读实际运动 |
| 支撑采样 | 按身体宽度及接地间隙查询，减少仅中心探针带来的窄边支撑抖动 |

V7 曾将坡面 Y 与独立水流／平台携带区分；K11 保留作用原因与一次消费边界，不保留旧裁剪字段。

## 当前限制

- 持续速度支持 Vector2，限时速度和动态力当前仍主要作用 X；真实动量由刚体累积，重力／跳跃单独处理 Y，完整二维来源语义仍后置。
- K11 运动改以实际刚体速度为基准；地面、平台、水流与主动运动保留来源边界，不以平台携带替代竖直环境作用。
- 旧 AABB 纠偏、有限回算与 X 向传力已退出；平地 1–3 箱自动通过，V4 原场景、任意箱链与多箱上坡仍未完整验收。
- 当前物理根节点冻结旋转；装饰旋转不代表旋转碰撞已经接入。
