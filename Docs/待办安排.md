### 认知扣费核对结果

| 入口 | 当前代码／基础配置 | 新降费接入要求 |
|---|---|---|
| 背包入包 | EnvironmentEditDraft → CognitionBackpack.AcquisitionCost → LevelCognition.TryPayAbilityCost；SceneLevelSetup 分别配置性质和计算点获取价 | 两种获取价共用倍率；仅最终新增入包收费，初始装载／失败恢复免费，出包不收费 |
| 地图占用 | LevelMapRecord → OccupyMapCost；每个 MapCell 配置 CognitionCost | 记录实际占用金额，取消仍退原记录金额，不能按升级后的新价格退款。面板展示当前倍率及实际格子价格／范围 |
| 成功转换 | PlayerLifecycleRules → PayFormCost；SceneLevelSetup 配基础转换价 | 手动和强制成功转换都乘同一倍率；失败不收费，初始进入不收费，冷却规则不变 |
| 模拟计时 | PlayerLifecycleRules → PaySimulationTime；SceneLevelSetup 配每秒价 | 本轮保持基础值，不加降费能力 |

这些入口语义已分开，但背包与逃生购买共用 TryPayAbilityCost，**不能在 Spend 或该通用支付方法上整体打折**，否则随机能力、刷新和保留费也会被误改。基础配置保持制作原值，消费者结算时读取有效倍率。第一层面板适合加固定三项降费，前提是先完成生效／回滚／存档，不仅加三个按钮。

退出核对：当前 ReturnToMenu 已作废加载请求、释放阶段规则／输入／角色并 ResetCurrentLevel；EnterSavedLevel 仅读关序，重新组装教学或探索／漫游。整个应用退出没有写阶段或临时效果的入口，现有代码符合这条边界，无须新增退出保存。下一关安置成功才写关序；P4 存盘只补已确认永久项，不能在退出时把临时列表写进去。检查依据与既有回归见历史。
