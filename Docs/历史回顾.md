## 人工编辑场景流程

当前制作接点；新待办未实现前，按现有 P6–P9 规则试玩。

1. **统一基础性能。** 在「自定义工具／开发工具／角色／基础性能统一」选来源／目标，核对差异后同步；默认以本体为准。共享物理配置、状态机资源默认与最终手感也需核对；新增能力经共用效果记录接入。
2. **先摆地形、箱子和出生点。** 本关只留一份 SceneLevelSetup；普通探索关关闭 Teaching，关联 Body Spawn／Spirit Spawn／Spirit Prefab；未接地图时关联 TrialStart。关卡里的 Main Camera 只提供背景色和正交尺寸，运行时由第一台游戏镜头常驻接管并关闭关卡镜头及其音频监听器。界面摄像机不合并。换关用现有加载页盖住，揭开前镜头已对准新角色。像素化遮罩仍未做。
3. **补可编辑环境宿主。** 按用途挂 BaseGround／Wall／WaterRegion，同物体唯一 BasicPhysicalObject 家族组件与 Collider2D；有限参数每类最多一项。无数值宿主也能框选看信息，裸碰撞框不能编辑；颜色／屏幕线宽在 GameplayPanel 的 EnvironmentEditView 配置。运行中修改经漫游面板，制作默认在 Inspector 设置。
4. **铺地图和安全中心。** 拖入 [MapCell](../Assets/MyObjAssets/gameObject/Pf/Map/MapCell.prefab)，实例位置为中心，宽高是世界单位、不随缩放变；可以留缝或接边，面积不重叠；人走到缝里后，重置仍用上一格中心。在 SceneLevelSetup 启用地图、关联全部格子；保证角色完整行走框以碰撞框中心安置后不嵌入默认箱子／地形，不运行时搜索替代落点。
5. **关联上涨水与通关入口。** 水为水平 BoxCollider2D Trigger，启用 Swimming Enabled，将实际 WaterRegion 填入 Rising Water 并调 Water Rise Speed；未关联水池保持静态。摆 SceneProp，Trigger 和脚本在同物体；Clears Level 在教学／逃生才通关，Has Effect 当前尚不附加能力。
6. **保存并核对关序。** 构建列表启用场景、名称唯一；「自定义工具／开发工具／关卡／关卡顺序」生成顺序文件。当前 TeskScenes1 → TeskScenes2；新增后续关后补引用。
7. **从开始场景验全流程。** 漫游改值／框选 → 模拟移动起跳 → 试验重置保留改值 → 地图中心传送 → 逃生购买与涨水 → 故意失败核对环境／箱子／地图／认知／道具回滚 → 再逃生靠近通关物 → 下一关 → 返回菜单重进。逐项复验遗留 V，再在实际包检查布局、数值与手感。
