## 框架演变

最初为平台稳定、地面跳跃与墙滑／墙跳建立可控相位。随后集中预测 AABB，增加实体纠偏、环境裁剪、残余回算、阻挡传播和 T+1 接触力；Unity Dynamic 又会修正实际落点，相位 4 成为主要协调成本。

F5 完成运动快照与环境入口：CollectSources → SynchronizeSources → SampleGroundFrame。环境关系归实体，来源只留身份，能力与几何分开；脚下／区域与侧墙各有用途。F6.1 收束效果数值，F6.2_1–7 前移请求求解并增加有限反馈；完整二维模型与任意箱链未完成。

N=1、T+1 和静墙分域是当时方案，未作为永久要求。旧单边施力已删除，不保留第二物理世界、无界递归或迭代中反复提交位移。K9 明确数据与引擎窄口；K8 将观测独立且只读。

2026-10-07 确定 K11，2026-10-08 完成六相位原生迁移：相位 3 合成并写刚体速度、4 统一模拟一次、5 回读实际，旧预测纠偏／裁剪／回算／传力及两策略接口退出。环境效果只持参数，真实动量归刚体；选中拉动用水平贴合、竖直自由的原生滑动关节。自动回归通过，人工手感与缺陷原场景仍待核。普通箱允许下方顶起；跳跃／墙滑仍由规则决定。
