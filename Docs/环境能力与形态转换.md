# 环境能力与形态转换

2026-10-10 · K7／P14 的有限环境编辑已实现，定向验证结果与待验范围见[待办安排](待办安排.md)。玩法与刷新所有权以[大纲](玩法大纲.md)为准；本文记录已确认的环境配置、物理接入与实现边界，不另起通用材料系统。

## 唯一来源与固定能力槽

同一物体只有一个 `BasicPhysicalObject` 环境宿主和一个 `EnvironmentRegistration`。宿主保存制作配置，首次读取时生成独立运行副本及默认快照；确认编辑不替换宿主、组件或来源身份。列表不保存角色速度、氧气、认知、地图或每个接收者的接触状态。

碰撞器／触发器各有 N 个固定槽，独立占用，共读一个槽上限。抽取后槽保留为空，两套列表在几何切换后仍保留。顶部开关只浏览列表；当前几何对应列表生效，另一列表置灰，禁止注入和计算，仍可抽取。同一列表每种性质至多一项。另有独特触发器性质槽，不占 N：注入转触发器，抽取转实心并把性质放回背包。

| 有限性质 | 列表及接触条件 | 计算语义 |
|---|---|---|
| 地面消退响应 | 碰撞器；由该来源支撑时采样 | 原消退倍率 × 点倍率，沿旧响应公式，不当作原生摩擦 |
| 普通起跳倍率 | 碰撞器；普通跳跃执行时消费 | 原倍率 × 点倍率，不自动合并墙跳 |
| 墙滑能力及系数 | 碰撞器；该来源为有效墙面且实际墙滑 | 原墙滑倍率 × 点倍率；抽走则不再提供墙滑 |
| 水四向能力 | 触发器；同源水几何与游泳开关 | 不参与计算；附带水事实，水面规则沿 P5.3 |
| 主动移速修饰 | 触发器；区域命中且性质存在 | 原有符号偏移 × 非负点倍率 |
| 被动双轴速度 | 触发器；区域命中且性质存在 | 原 Vector2 两轴同乘倍率，保留方向与原值 |
| 独特触发器性质 | 独立几何槽 | 不参与计算，不进入普通能力列表 |

每项性质最多附加一个不可变乘法点。性质保留原值与点身份，结果按原值计算；不反复乘上一次结果。制作端已有表面／水／速度字段只在缺少显式性质时生成初始项；运行后抽取不再由旧字段补回。初始背包允许同类多个内容物，与来源列表的同类限制不同。

## 面板、背包与统一确认

环境面板在中下方，背包在右侧，可同时显示。空槽打开背包并高光兼容性质；已有槽高光兼容计算点。水能力等不支持计算的项不高光计算点。停用列表只保留抽取按钮。

独特触发器性质初始不给，须从普通触发器抽取并确认后取得。点选实心环境的独特槽有持续高光和选中说明；联动背包没有此性质时提示先抽取并确认，有时高光可注入项。

`PlayerLifecycleRules` 持有本关唯一 `CognitionBackpack` 与当前 `EnvironmentEditDraft`，沿既有 `LevelCognition` 结算。UI 只操作草稿，不写玩家效果容器或环境生效数据。每次编辑复制来源的两套槽与背包，记录来源／背包版本；结果即时展示，点仍在背包预览中标记目标。未确认点改挂新目标时解除原预览，同一点不同时附着两处。

性质与附加点整体抽取为一个内容物。背包拆点按钮仅作用于背包中带点的性质；已确认附加点不能直接在环境槽上替换，须先整体抽取再拆点。背包独立打开时所有内容槽与拆点按钮只读；有环境草稿时可显示同一预览，操作仍须由环境槽联动。

计算、注入、抽取、拆点、几何切换由整个环境面板确认一次：复核漫游资格、同关来源、配置版本、性质兼容、点唯一归属、容量及余额，通过后提交来源、背包并扣费。真实最终新增入包内容物收费，出包无额外收费；预览搬回原位置不重复收费。初始装载和失败恢复免费。拒绝时无部分转移或付款，重复确认不会再次扣费。

切换浏览列表保留草稿；关闭／取消环境面板丢弃预览。已有改动时换环境、手动切换模式或主动开始逃生，必须先确认／取消，不能隐式确认。认知耗尽自动结束探索时取消未确认预览，保留已确认配置。菜单关闭编辑区也结束未确认草稿。

## 有效能力与物理管线

接口表示宿主具备接入契约，有效列表表示该项当前存在。`EnvironmentCapabilities` 统一解析已提交列表：抽取即缺席，零值仍是一项存在的能力。脚下、墙滑、水事实和持续效果消费点都读同一来源配置，避免按旧类接口把已抽取性质补回。

`EntityEnvironmentContext` 继续持有接收者与来源关系，在原相位 2 核对来源及各项效果：

| 同来源变化 | 处理 |
|---|---|
| 某持续项新增 | 按该项登记，保留其它凭据 |
| 某持续项移除 | 仅撤销该项，不整源退出 |
| 某项参数改变 | 经已有效果写口覆盖参数，保留刚体实际动量 |
| 脚下／墙滑／水能力改变 | 重新采样，不造虚假持续效果 Binding |
| 来源完全离开、禁用或销毁 | 沿原 Detach／ReleaseAll 清理实际登记 |

角色真实动量仍归刚体，环境配置不保存来源速度库存或尾效。UI 不逐接收者直接写值，也不要求实体先出区域再进入才能刷新。六相位、普通运动公式、推箱与平台管线保持既有职责。

水事实、游泳可用性、物理速度效果分开：水性质仍在但游泳开关关闭，淹没仍可供氧气规则读取；抽走水性质或切为实心后不再是当前水来源。多水域的淹没与游泳启用必须来自同一水源，不能跨来源拼接。飞行优先且穿墙，期间不消费外部水、地面、墙滑、平台或力场；退出飞行重新采样当前事实。

## 固定几何、主水与占用提示

本轮只控制同一宿主已有面积碰撞体的 `isTrigger` 与必要检测层，不生成流体或任意几何。Box／Circle／Capsule／Polygon 可进入有限修改；Edge、Composite 及由 Composite 接管的形状在整次确认前拒绝。旧水域在 Default 等非地形层时，恢复实心映射到现有 Ground 检测层，转回触发器恢复制作层；既有 Ground／Wall 保持原层。不修改全局查询 mask。

触发器不自动赋予水能力。恢复实心也不自动生成冰面算法；已保留的碰撞器列表重新生效。平台位移 `IPlatformMotion`、原 IceGround／Taijie 固有动态算法及 ForceField 的原动态力算法仍是固有接入，不是此次新增的可抽取性质。对应原生几何模式停用时悬置，有限水／移速／被动速度性质按有效列表解析。不扩任意动态力公式或通用算法内容物。

上涨主水体由 `SceneLevelSetup.RisingWater` 指定，属于关卡专用效果，拒绝玩家编辑且不绘制蓝框；水位、上涨许可和失败默认恢复沿原关卡入口。普通可编辑水域不会并入主水。

面板提示区域内可推动实体：登记普通箱及外部带电箱，排除玩家、其它环境和已收纳箱。暂停箱子可能不参与原生重叠查询，所以按登记对象、实际刚体位置及配置几何检查。栏目仅提示，不拒绝转实心，不推离实体或搜索安全位置。精神体恢复行走仍执行既有当前位置浅重叠校验；落点制作要求沿大纲。

## 轻／重刷新

模式切换和模拟死亡保留已确认列表、几何、点及背包。试验重置／开始逃生的轻刷新保留这些内容，仅按原入口恢复箱子等运行状态和角色位置／资源，再重采样。

逃生失败重刷新按原 P9 顺序：暂停操作／运动、停止水上涨；各环境来源恢复首次捕获的默认槽、空槽、几何及层，主水还原默认水位与许可；恢复箱子、认知、道具及新增效果；按本关配置免费重建背包，安置角色并核对关系，交出唯一控制目标，返回暂停世界的漫游。启停组件和轻刷新不得重新把已修改配置捕获为默认。

完整检查范围包括草稿改挂与取消、点唯一归属、整体抽取及拆点、停用列表抽取、统一费用／容量失败、默认恢复、同源持续项差异与动量、主水排除、暂停箱提示以及现有阶段／UI 流程。自动结果与实际关卡手感分开记录到待办，不以编译通过代替 Unity 行为验证。
