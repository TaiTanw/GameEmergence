维护规则：

- 未正式开工的项目默认只在待办表写问题、方向与状态；用户明确要求专题拆单元时可开文档记录边界，不预铺实施步骤和求解公式。
- 正式开工且需要独立记录时，在 `Docs/待办具体事务文档集中/` 增加 `P_编号-主题.md`、`V_编号-主题.md` 或 `K_编号-主题.md`；待办表只留入口。已有 `F_6`、`F_8` 文件名保持不变。
- 完成后把必要结论收进历史回顾，删除过期步骤、重复正文与跳转兼容页。
- 旧编号文档已合并，不再维护多份执行入口。历史图只辅助回顾，不作为现码依据。
