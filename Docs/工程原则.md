# 工程原则

当前实现边界与已确定的收束方向。玩法与数据所有权见[玩法大纲](玩法大纲.md)，任务见[待办安排](待办安排.md)，代码入口见[项目 README](../README.md)。

## 分层原则

1. 宿主负责组装、调度和生命周期，规则尽量用普通类型表达；按实际用途保留接口，不预建万能适配层。
2. 输入 → 实际类别 → 行为策略 → 执行 → 表现。下层不回写上层内部状态，跨层走明确接口和只读事实。
3. FSM 决定能否做、做什么；执行负责运动与效果，FSM 不写 Rigidbody2D、不积分重力。
4. 几何命中与环境能力分开：实心表面可以阻挡，命中不等于能墙滑或游泳。
5. EntityEnvironmentContext 持有来源关系；源端只留身份与清理索引；EntityEffectState 只持环境与限时命令参数，真实累积动量归刚体。
6. 新效果优先接现有能力与运动合成，不为每种效果加全局相位、回调链或独立速度库。
7. Player 组装与输入接入、FSM 行为、CharacterPhysics／BasicEntity 执行、PresentationLayer 表现各守职责。
8. 配置外置，探测层、尺寸、开关和手感参数有明确归属；重构不顺手改名或迁移序列化数据。
9. 新增制作参数提供清楚的编辑器入口与可试用默认值，最终数值和场景搭配由人工调整。非法配置显式指出对象／错误项并拒绝对应执行，不静默改值、替换关联或搜索替代落点；保留必要运行校验，不扩自动纠正系统。未定玩法含义先核对，不以数值默认值替代人工决策。P20 已确认的属性上下限属于玩法规则：合法正负效果先完整计算，再对最终有效值限界一次，中间不截断；这与非法配置的显式拒绝分开，不以限界掩盖反向范围、NaN／Infinity 或错误引用。

**K11 实现完成，自动回归通过；人工手感与原场景验收待核。** 角色与箱子保留 Dynamic，由 Script 模式在固定步长统一模拟一次。

| 相位 | 当前职责 |
|---|---|
| 0 | 平台运动产生 Delta、水更新范围与水位，同步几何 |
| 1 | 读取上一步原生接触；探针、单向平台与区域查询 |

## 本轮收束结果

**K11 重点收束相位 4 的实体间解算。** 保留感知、环境参数、动作意图与行为时序。预测 AABB、残余回算、方向传播、T+1 接触传力和两套求解策略接口已删除，不再逐帧 MovePosition。静墙、可爬坡面和头顶仍在写入速度前按几何收一次，避免默认摩擦粘墙和上坡挤跳。驱动者先写第一只侧面箱子的水平速度；关节锁住的那一对不改写，随后一次模拟处理实体接触。

原生接触在相位 1 主动查询，来自上一步完成的模拟；跳跃、墙滑／墙跳仍归规则，不改由碰撞生命周期回调决定。动作／环境合成与碰撞响应各有唯一归属，不叠加旧逐步位移。

P5.4 选中、推拉、收纳和占用拒绝保留；原共同水平请求改为竖直自由、水平贴合的原生滑动关节，跳跃／落边解除。锚点基于双方刚体实际位置差转换，不读取滞后的插值显示位置。普通箱允许从下方顶起，但关卡不依赖此玩法。冰面／推拉手感尚未定标，允许重调。详细范围只维护在[K11](历史回顾.md#k_11框架复杂度降低)。

## 数据与生命周期边界

| 数据／关系 | 所有者与用途 |
|---|---|
| Rigidbody2D、PlayerPhysicsData | 刚体实际速度为唯一跨帧运动基准；动作参数不继续累计已被碰撞改变的旧竖直速度 |
| EntityEffectState | 环境与限时命令参数，不保留接触传力、累积动量或来源尾效库 |
| GeometryPhysicsData、PhysicalFunctionData | 几何事实与角色墙能力分开 |
| EntityEnvironmentFrame、EntityWaterFrame | 本步表面／水事实，不拥有累计速度、氧气或泳姿 |
| 本步运动命令、模拟结果 | 当前意图与实际运动分开；环境与平台贡献只消费一次，重力只保留一个计算入口；持续速度与角色主动 X 的回读量仅避免重复合成 |
| PlayerBoxSelection、PhysicalBox | 玩家拥有选中关系，箱子拥有收纳状态；表现消费结果 |

环境发现当前仍要求 Collider 同物体的唯一 BasicPhysicalObject。接触查询排除 Trigger，水等区域查询收 Trigger；不改全局查询开关。持续能力接口存在与启用值分开，无持续能力不建 Binding。地面／水事实不依赖 Binding；持续效果参数差异更新仍归 K7。

IsMotionReady 表示组装就绪，IsMotionPermitted 表示规则许可，IsMotionParticipating 表示实际参与；IsSupported 仅表达箱底几何支撑。暂停保留运动状态并停止参与模拟；恢复为 Collider → 参与同步 → 采样，显式重置才清运动。simulated 同值不重复写入。

资源归 FSM，死亡按周期请求给规则层。场景／规则侧拥有长期实体与本关精神体，InputControlMgr 只拥有当前控制目标；Player 不承担整关阶段编排。模式切换保现场，轻重刷新由 P6/P9 统一编排，不让 Awake／OnEnable 或环境脚本全量重置。精神体飞行、漫游／模拟、转换结算与 P8/P9 的最小逃生／刷新已接入；完整普通道具和新增分支仍按待办核对，规则见大纲。

## 调试与验证

- 观测只复制事实，不回写速度、位置、来源或求解结果；编辑器专用声明与计算用 UNITY_EDITOR 隔离。
- 运行时混用的观测字段／入口用 debug／Debug 标识；正式计算不能因用于显示而移入编辑器宏。
- 以 fixedTick 对照本步命令与相位 5 模拟结果，不每帧大量打印。提示预览不产生操作拒绝日志。
- 编译、Edit Mode、Play Mode 与人工试玩各有边界。按行为复用夹具，局部先定向验证，结构稳定后完成相关回归，不新增镜像实现的测试。
